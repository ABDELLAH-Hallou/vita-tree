        Input & environment
        Use an existing UTF-8 LaTeX project with main.tex at the collection root and all of its local classes, styles, fonts, images and includes. PDF, Word and scanned-CV import are not supported.
        Checks compile a temporary copy with shell escape and automatic package installation disabled. Project files are preserved. No AI service is contacted. Only open templates and TeX installations you trust; these restrictions are not an OS sandbox.
        Automatic uses XeLaTeX when main.tex declares fontspec, polyglossia or unicode-math; otherwise PDFLaTeX. Choose explicitly when a class or included file requires another engine. Retries preserve their captured engine.
